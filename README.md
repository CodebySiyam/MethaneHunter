# MethaneHunter

MLOps pipeline for methane plume detection and analyst review prioritization
from Sentinel-2/Landsat imagery. Research prototype: outputs are candidates
for expert review, not confirmed emissions.

Data: MARS-S2L (UNEP-IMEO), CC BY-NC-SA 4.0, not included in this repo.
Citation: Mateo-Garcia, Allen, Irakulis-Loitxate et al., arXiv:2511.21777.
